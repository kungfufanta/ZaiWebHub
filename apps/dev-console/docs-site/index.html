Tổng quan

Hub cung cấp endpoint chat kiểu OpenAI (`POST /v1/chat/completions`, SSE) + API nội bộ cho worker pool.

Base URL qua gateway công cộng của sandbox hub: https://<hub-host>/<path>?XTransformPort=3003 — gateway Caddy forward theo query XTransformPort, hỗ trợ cả WebSocket upgrade. Trong nội bộ sandbox hub: http://127.0.0.1:3003. Trang này tự điền base URL hiện tại của bạn vào ví dụ (thay {HUB}).

WS /worker — worker protocol

Worker TỰ connect outbound tới `wss://<hub-host>/worker?XTransformPort=3003` — hub không bao giờ inbound vào sandbox worker.

  • Frame ĐẦU TIÊN phải là worker.register hợp lệ (token + tenant + protocol_version khớp) — sai bất cứ điều nào → close 4401.
  • Duplicate worker_id (2 connection cùng ID) → connection cũ bị thay, close 4409.
  • Heartbeat > 45s → sweep coi worker chết (sweep mỗi 10s); job.ack phải tới trong 30s sau dispatch (visibility timeout).
  • Control frames = JSON TEXT; job chunk = BINARY envelope F4: [16B job_id][4B seq BE][raw SSE bytes nguyên xi] (header 20 bytes).
ChiềuFrameGhi chú
W → Hworker.register {type, capabilities, token}capabilities: {worker_id, tenant_id, models[], concurrency, protocol_version}
W → Hworker.heartbeat {type, ts, inflight}inflight authoritative
W → Hjob.ack {type, job_id}trong 30s sau dispatch
W → Hbinary job.chunkenvelope F4 — raw SSE bytes relay nguyên xi
W → Hjob.done {type, job_id, finish_reason, usage?, upstream_done_relayed?}upstream_done_relayed:true → hub không flush thêm [DONE]
W → Hjob.error {type, job_id, error:{message, type}}trước chunk đầu → requeue (max 1); sau chunk → event:error + [DONE] cho client
H → Wjob.dispatch {type, job}job = JobPayload đầy đủ
H → Wjob.cancel {type, job_id, reason?}user disconnect / hub cancel
H → Whub.ping {type, ts}keepalive

Chi tiết đầy đủ của wire contract: packages/protocol/src/frames.ts (zod — 2 đầu validate) và docs/api.md.
